⚡ 60-Second Terminal Quickstart

Zero Proprietary ROMs Required 
# 1. Clone repository
git clone https://github.com/yefan911/automated-recompilers.git
cd automated-recompilers

# 2. Recompile included legal homebrew ROM to native .exe
python recompile.py roms/test/hello_gba.gba

# 3. Launch native game window (Direct Win32 Framebuffer, zero emulator overhead)
.\build\hello_gba.exe --window

# 4. Or launch the dark-mode desktop GUI
python recompile.py --ui
